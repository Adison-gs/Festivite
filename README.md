## 📖 Sobre o projeto

O **Festivite** é uma aplicação desenvolvida para permitir a criação de convites digitais para diferentes tipos de eventos.

O usuário pode preencher informações importantes sobre o evento, como:

- 📝 Nome do evento
- 📅 Data e horário de início e término
- 📍 Localização
- 🏢 Tipo de evento
- 🎨 Tema do evento
- 🌙 Estilo claro ou escuro
- 🖼️ Foto de capa
- 👤 Dados de contato

O projeto possui diferentes opções de temas para eventos, como aniversários, casamentos, formaturas, festas infantis, Natal, Halloween e outros.

---

## 🚀 Tecnologias utilizadas

Este projeto foi desenvolvido utilizando:

- HTML5
- CSS3
- Google Fonts

---

## 🎨 Funcionalidades

- Criação de convites digitais
- Seleção do título do evento
- Escolha de data e horário
- Seleção entre evento presencial ou online
- Escolha de tema para o evento
- Alternância entre estilo claro e escuro
- Upload de imagem para a capa
- Preenchimento de informações de contato
- Campos para aceite dos termos e recebimento de atualizações
